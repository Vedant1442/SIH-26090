# SIH-26090 - Kala Sangam

This repository contains the source code for our Smart India Hackathon (SIH) project. It is a full-stack application featuring a mobile frontend and a Python backend.

## Project Structure

- **mobile_new/**: Contains the mobile/web frontend code for the application.
- **backend/**: Contains the Python backend, including API routes, AI endpoints, and database models.

## Getting Started

### Backend
1. Navigate to the `backend/` directory.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the backend server.

### Frontend
1. Navigate to the `mobile_new/` directory.
2. Install dependencies: `npm install`
3. Start the development server.

## Features

- **Discover & Catalog**: Explore content and manage catalog entries.
- **AI Chatbot**: Integrated AI features to assist users.
- **Team & Onboarding**: Smooth user onboarding and team management interfaces.
- **Offline / Export**: Capability to capture data and export.
